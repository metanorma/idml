| Name | Type | Req | Description |
| ----------------------- | -------------------------------------- | ------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ChapterNumberFormat | NumberingStyle_EnumValue or string | no | The chapter numbering type, as a NumberingStyle enumeration or as a string. The string corresponds to the options found on the Style pop-up menu in the Document Chapter Numbering section of the Numbering & Section Options dialog box in InDesign's user interface. Can be UpperRoman, LowerRoman, UpperLetters, LowerLetters, Arabic, Kanji, KatakanaModern, KatakanaTraditional, FormatNone, SingleLeadingZeros, ArabicAlifBaTah, ArabicAbjad, HebrewBiblical, HebrewNonStandard, DoubleLeadingZeros, or TripleLeadingZeros. |
