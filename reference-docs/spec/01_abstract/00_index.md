# 1 Abstract

IDML is an XML representation of an In  Design document or components. This document describes the structure of IDML files, the XML schema for IDML validation, and provides examples of IDML file content. This document has been updated for IDML version 8.0, which corresponds to InDesign CS6. For the list of content updates in this version, refer to 'Appendix E. Update List of IDML 8.0' .
