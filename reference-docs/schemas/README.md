# IDML Schemas

Relax-NG Compact syntax (`.rnc`) schemas for Adobe IDML, generated by
InDesign's `app.generateIDMLSchema()` API.

## Source

- **InDesign version**: 2026 (21.5.0.64)
- **DOMVersion**: `21.5`
- **Generator**: `app.generateIDMLSchema()` (Adobe InDesign IDML Cookbook, "How do I generate a schema?")
- **Generation scripts**: `../plugin_sdk_21/devtools/idmltools/scripts/{GenerateSchema,GeneratePackageSchema}.jsx` (edited to write into this directory)
- **Generation date**: 2026-08-01
- **Validator**: Jing 20030619 at `../plugin_sdk_21/devtools/idmltools/jing/bin/jing.jar`

## Known Adobe bug (patched)

`app.generateIDMLSchema()` leaks raw documentation prose into `datatype.rnc`
at lines 177–196 — a wiki-style table about Folio metadata that should have
been emitted as RNC comments. The leaked range is invalid RNC, and every
downstream part file fails validation because the parse failure cascades:
all `*_EnumValue` references declared in `datatype.rnc` become undefined.

The patch (in `fix-adobe-schema-bug.rb`) comments out the broken prose
range idempotently. It matches the fix PatrickAgostini applied in their
pre-extracted schemas at `~/src/external/idml/schema/rnc/Packaging/datatype.rnc`.

## Regeneration procedure

1. In InDesign 2026, open `Window → Utilities → Scripts` (⌘⌥F11).
2. Double-click `GeneratePackageSchema.jsx` (under the **User** folder). Output lands at `reference-docs/schemas/package/`. Wait 30–60s.
3. Double-click `GenerateSchema.jsx`. Output lands at `reference-docs/schemas/single/`.
4. Run `ruby reference-docs/schemas/fix-adobe-schema-bug.rb` to patch both `datatype.rnc` files.
5. Sanity-check with Jing:
   ```bash
   java -jar ../plugin_sdk_21/devtools/idmltools/jing/bin/jing.jar -c \
     package/Spreads/Spread.rnc /path/to/Spreads/Spread_*.xml
   ```

## Version compatibility

These schemas are tied to InDesign 2026 (DOMVersion `21.5`). IDML files
saved by older InDesign versions will fail strict validation on:

- `DOMVersion` attribute mismatch (the schema hardcodes `"21.5"`).
- Attributes added after the file's source version (e.g. `TitleCheck`,
  `IsAnEndnoteStory`, `ParagraphBorderLineWeight`,
  `ParagraphShadeTopLeftCornerOption`).

This is expected. For round-trip testing, use IDML fixtures exported from
InDesign 2026. For round-trip of older IDML, strict schema validation is
unavailable — rely on byte-equivalence per part instead.

## Schema authority priority

For the `idml` gem, this directory is the highest-priority schema source
(canonical for the user's InDesign version). Lower-priority fallbacks,
in order: pre-extracted RNG/RNC at `~/src/external/idml/schema/{rng,rnc}/`,
spec markdown at `~/src/external/idml-schema/docs/idml-specification/`,
and Adobe's idmltools Java source for behavioral edge cases. See the
top-level `CLAUDE.md` for the full reference-material table.
